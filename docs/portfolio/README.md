## Моя роль и AI-assisted development

В проектах я формулирую цели и инженерные ограничения, проектирую сценарии и критерии приёмки, координирую AI-исполнителей (например, Codex, Claude Code, Gemini), анализирую результаты и принимаю решения о продолжении. Существенные части кода в ряде проектов сгенерированы AI-инструментами; я **не** представляю их как полностью самостоятельно написанный вручную код и **не** называю проекты коммерческими внедрениями.

## Интересы для работодателя

- Автоматизация повторяющихся внутренних процессов и документирование сценариев
- Формальные входные/выходные данные и обработка ошибок
- Контроль качества результатов LLM/агентов и независимые проверки
- Python API, JSON, SQL и воспроизводимые локальные демонстрации

**Не подтверждено:** работа с корпоративными CRM/почтой, production OAuth 2.0, фармацевтическими данными, внедрение ИИ для заказчика и измеренный бизнес-ROI. Такие результаты не заявляются.

## Приватность

Содержимое реальных БД, заявки, контакты, личные данные, приватная переписка, внутренние отчёты безопасности и секреты не включены. Исходные приватные репозитории не делались публичными. Для доступа к коду исследовательских систем сначала нужны отдельные очищенные демонстрационные копии с независимой проверкой.
