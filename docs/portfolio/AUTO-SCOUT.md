# AUTO-SCOUT — Python/SQLite и проверяемая автоматизация

**Тип:** личный локальный инструмент · **статус:** продолжающаяся разработка, не commercial product и не production crawler. Оригинальный репозиторий закрыт.

## Задача

Создать локальную систему для ручного учёта предложений с понятными состояниями, историей изменений и безопасным восстановлением данных. Неизвестные параметры остаются неизвестными; система не должна сама принимать коммерческие решения, открывать внешние URL или отправлять отклики.

## Архитектура и данные

```text
Ручной ввод в локальной веб-консоли / CLI / JSON
                    |
         проверка и нормализация
                    |
              SQLite (v2)
                /      \
     история / аудит    backup / verify / restore
                |
        локальный read-only / ручной workflow
```

Стек: Python 3.10+, SQLite, стандартная библиотека, локальный HTTP-интерфейс, JSON, unittest, Git и PR-review. В базовой ветке задокументированы ручной ввод, редактирование записей, история, статусы и резервное копирование. Источники реальных вакансий и автоматический сбор не подключены.

## Инженерный процесс и моя роль

Я выступаю инициатором, постановщиком задач и принимающим решения владельцем. Определяю сценарии, правила обработки исключений, требования к безопасности данных и критерии завершения задач.
