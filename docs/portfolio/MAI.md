# MAI — исследование архитектуры локального LLM-агента

**Тип:** личный исследовательский проект · **статус:** архитектурные эксперименты и локальные прототипы, не промышленное внедрение ИИ.

## Задача

Исследовать, как строить долгоживущий программный агент с контекстом, памятью, правилами поведения и явной обработкой внутренних состояний. Предмет проекта — агентная архитектура и сохранение последовательности поведения, а не утверждение о наличии сознания у ИИ.

## Локальная интеграция

```text
Локальное приложение / игровой контекст
                 |
        HTTP/JSON запрос
                 |
          Flask API (Python)
                 |
       Локальный LLM runtime
                 |
         JSON / текстовый ответ
                 |
   Правила поведения и слой представления
```

Проводились эксперименты с LM Studio, локальными моделями и Flask API; проверялись пути запросов, формирование контекста и возвращаемые ответы. Дальнейшая архитектура предусматривает отдельные компоненты памяти, self-model, intent/state и выражения поведения. Эти компоненты имеют разную степень зрелости; нельзя считать их целиком реализованными и проверенными.

## Моя роль

Постановка исследовательской цели, архитектурные решения, настройка локальной среды, технические пробы интеграций, проектирование сценариев и ограничений поведения. В реализации и анализе используются AI-инструменты; проект не представляет собой платное внедрение для третьей стороны.

## Что демонстрирует

- Понимание границы между LLM, API, состоянием приложения и интерфейсом
- Форматы входных данных/ответов и ограничения структуры JSON
- Декомпозицию агентной логики и проектирование долгосрочного контекста
- Необходимость проверки, безопасных fallback и честного отражения неопределённости

## Границы публикации

Проект связан с фанатскими материалами; сторонние персонажи, тексты, визуальные ресурсы и закрытые документы не публикуются в этом техническом обзоре. В нём нет исходного кода, бенчмарков автономности, результатов коммерческого внедрения или доказательств production-надёжности.
